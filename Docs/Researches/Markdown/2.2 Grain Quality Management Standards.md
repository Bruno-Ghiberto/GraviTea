grain trade as of 2024-2026. I need this to build quality management features in an

**Argentine Grain Quality Standards (2024‑2026)**
*Official sources: Cámara Arbitral de Cereales (CAC) – Bolsa de Cereales de Buenos Aires; SENASA; SAGPyA resolutions. The main reference is the “Cuadros de normas de calidad para la comercialización” (CAC, 2018) which is still in force and complemented by specific SENASA/SAGPyA resolutions for moisture, storage losses, and special parameters.*

## 1. Soja (Soybean) – Norma XVII (Res. SAGPyA 151/2008)

| Parameter | Base / Tolerance | Commercial deduction (rebaja) |
| :-- | :-- | :-- |
| **Humedad** | 13,5 % (no tolerance – excess triggers merma de secado) | Merma = [(Hᵢ – 13,5) × 100] ÷ (100 – 13,5) % of weight |
| **Materias extrañas** | 1,0 % / 3,0 % | >1,0–3,0 %: 1,0 % / cada % exceso; >3,0 %: 1,5 % / cada % exceso |
| **Incluido Tierra** | 0,5 % / 0,5 % | >0,5 %: 1,5 % / cada % exceso |
| **Granos negros** | 1,0 % (sin tolerancia) | >1,0 %: 1,0 % / cada % exceso |
| **Granos quebrados y/o partidos** | 20,0 % / 30,0 % | 20,0–25,0 %: 0,25 % / cada % exceso; 25,0–30,0 %: 0,5 % / cada % exceso; >30,0 %: 0,75 % / cada % exceso |
| **Granos dañados** (bro‑, fermentados, ardidos, podridos) | 5,0 % / 5,0 % | >5,0 %: 1,0 % / cada % exceso |
| **Incluido Granos quemados / “averia”** | 1,0 % (sin tolerancia) | >1,0 %: 1,0 % / cada % exceso |
| **Granos verdes** | 5,0 % / 10,0 % | 5,0–10,0 %: 0,2 % / cada % exceso |
| **Chamico (Datura ferox)** | 5 semillas / kg | Exceso → merma de peso y gastos de zarandeo (según tabla de semillas/kg) |
| **Condición (arbitraje)** | – | “Revolcado en tierra”, “olores comercialmente objetables”, “granos amohosados”: descuento 0,5 %–2,0 % según intensidad |

**Grade table** – Soybean is traded under “condición Cámara”; no formal Grado 1/2/3 classification is defined in the Norma XVII; tolerances above apply directly.

**Official entity** – Cámara Arbitral de Cereales (CAC) – Norma XVII (Res. SAGPyA 151/2008).

**Merma de almacenamiento** – 0,5 % de materia seca por mes (condiciones normales de silo) $$

$$.

**Factor de conversión (húmedo → seco)** –

$$
F = \frac{100 - H_{\text{actual}}}{100 - H_{\text{base}}}
$$

where $H_{\text{base}} = 13,5\%$.
**Merma de secado** – same formula as above (pérdida por exceso de humedad).
**Zarandeo (dockage)** – applied as per the rebajas for Materias extrañas, Incluido Tierra, Granos quebrados, etc.

## 2. Maiz (Corn) – Norma XII (Res. SAGyP 1075/94)

| Grado | Peso hectolítrico mínimo (kg/hl) | Tipo % | Color % | Granos picados % | Humedad % | Granos dañados % | Granos quebrados % | Materias extrañas % |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| 1 | 75 | 3,00 | 2,00 | 1,00 | 5,00 | 5,00 | 3,00 | 14,5 |
| 2 | 72 | 5,00 | 3,00 | 1,50 | (not shown – typically ≤14,0 %) | 8,00 | 5,00 | 2,00 |
| 3 | 69 | 8,00 | 5,00 | 2,00 | (not shown) | — | — | — |

*Note: The humidity column in the PDF refers to the maximum allowed humidity for each grade; the commercial base humidity for maize is **14,0 %** (excess triggers merma de secado).*

**Commercial deductions (rebajas)** – applied when a parameter exceeds its tolerance for the contracted grade:

- **Humedad**: Merma = [(Hᵢ – 14,0) × 100] ÷ (100 – 14,0) %
- **Granos dañados**: > tolerance: 1,0 % / cada % exceso
- **Granos quebrados**: > tolerance: 0,5 % / cada % exceso (for Grado 1) – values vary by grade
- **Materias extrañas**: > tolerance: 1,0 % / cada % exceso (up to a limit, then arbitration)
- **Olores objetables / Granos amohosados**: 0,5 %–2,0 % según intensidad
- **Chamico**: 1,3 % de merma de peso y gastos de zarandeo (2 semillas / 100 g)

**Grade‑based bonuses/rebajas** – Grado 1: +1,0 % bonificación; Grado 2: 0; Grado 3: –1,5 % rebaja.

**Official entity** – Cámara Arbitral de Cereales (CAC) – Norma XII (Res. SAGyP 1075/94).

**Merma de almacenamiento** – 0,5 % de materia seca por mes $$

$$ (alternatively 0,075 %/mes según EMAPA $$

$$).

**Factor de conversión** – $F = (100 - H_{\text{actual}})/(100 - 14,0)$.
**Merma de secado** – same as humidity formula above.
**Zarandeo** – deductions for excess of Materias extrañas, Granos quebrados, Granos dañados, Chamico, etc., as per the tolerance tables.

## 4. Trigo duro (Durum Wheat) – Norma XX (same as trigo pan, with adicional)

The Norma XX states: *“EL TIPO DURO ADMITIRA COMO MAXIMO UN 5% DE VARIEDADES SEMIDURAS”.*
All other parameters (humedad, proteína, gluten, número de caída, vitreosidad, tolerancias) are identical to trigo pan.
**Official entity** – Cámara Arbitral de Cereales (CAC).
**Merma de almacenamiento, factor de conversión, merma de secado, zarandeo** – same as trigo pan.

## 8. Maní (Peanut) – Relevant for acopiadores in Córdoba

### a) Maní descascarado para industria aceitera – Norma XIII – Anexo C (Res. SAGPyA 12/99)

- **Contenido de materia grasa (S.S.S. y L)**: 44,0 % base
>44,0 %: +1,5 % / cada % exceso; <44 %: –1,5 % / cada % déficit
- **Acidez de la materia grasa**: 1,5 % base
>1,5–3,0 %: +2,5 % / cada % exceso; >3,0 %: +3,0 % / cada % exceso
- **Tierra**: 0,5 % / 2,5 % → >0,5–2,5 %: 2,0 % / cada % exceso; >2,5–5,0 %: +2,5 % / cada % exceso; >5,0 %: +3,0 % / cada % exceso
- **Cuerpos extraños**: 0,5 % / 6,0 % → >0,5–6,0 %: 1,0 % / cada % exceso
- **Humedad**: 9,0 % base (exceso → merma de secado según tabla oficial)
- **Libre de insectos y arácnidos vivos** – obligatorio
- **Arbitrajes**: “Granos revolcados y otras causas de calidad inferior”: descuentos 0,5 %–2,0 % según intensidad


### b) Maní confitería – Norma XIII – Anexo D (Res. SAGPyA 12/99)

- **Humedad**: máximo 9,0 % (same as above)
- **Granos quebrados y/o partidos (no revolcados)**: máximo 4,0 % (oct‑abr) → 6,0 % (abr‑oct)
- **Insectos y arácnidos vivos**: libre
- **Grano de otro color**: máximo 1,0 %
- **Revolcado**: libre
- **Tierra**: máximo 0,1 %
- **Granos alterados en su presentación**: máximo 5,0 %
- **Granometría**: clasificación según número de granos en 28,35 g (escalas de 10 en 10 hasta 80, luego de 20 en 20).

**Official entity** – Cámara Arbitral de Cereales (CAC) – Norma XIII – Anexos C‑D (Res. SAGPyA 12/99).

**Merma de almacenamiento** – 0,5 % de materia seca por mes $$

$$.

**Factor de conversión** – $F = (100 - H_{\text{actual}})/(100 - 9,0)$.
**Merma de secado** – same humidity formula.
**Zarandeo** – deductions for excess of Tierra, Cuerpos extraños, Humedad, etc., as per tolerance tables.

### Resumen de fórmulas clave

| Concepto | Fórmula | Comentario |
| :-- | :-- | :-- |
| **Factor de conversión (húmedo → seco)** | $F = \dfrac{100 - H_{\text{actual}}}{100 - H_{\text{base}}}$ | Peso seco = Peso húmedo × F |
| **Merma por secado (exceso de humedad)** | $\% \text{ merma} = \dfrac{(H_i - H_b) \times 100}{100 - H_b}$ | $H_i$ = humedad inicial, $H_b$ = humedad base |
| **Merma por almacenamiento (pérdida de materia seca)** | 0,5 % de materia seca por mes (condiciones normales de silo) $$

$$ | Alternativa: 0,075 %/mes (EMAPA) $$

$$ |
| **Merma por zarandeo (dockage)** | Según tablas de tolerancia: para cada parámetro, $\% \text{ rebaja} = k \times (\text{valor actual} - \text{tolerancia})$ donde $k$ es el factor dado en la norma (ej. 1,0 %/%, 0,5 %/%, 0,25 %/%, etc.) | Se suma el efecto de todos los conceptos que excedan su tolerancia |
| **Bonificación/rebaja por grado** | Grado 1: +X %; Grado 2: 0; Grado 3: –Y % | X, Y específicos de cada grano (ver tablas) |
| **Bonificación por proteína/trigo** | >11,0 %: +2,0 % / cada % >11,0; <10,0 %: –2,0 % / cada % <10,0 (solo si P.H. ≥75 kg/hl) | Aplicado al precio base |
