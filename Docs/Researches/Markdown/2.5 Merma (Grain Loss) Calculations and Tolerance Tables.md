# Merma en Operaciones de Acopio de Granos en Argentina: Tablas, Fórmulas y Normativa

## Resumen ejecutivo

Las mermas en el acopio de granos en Argentina no son un porcentaje fijo arbitrario sino que se calculan con fórmulas específicas basadas en los parámetros de calidad de cada lote entregado. La normativa se origina principalmente en resoluciones de la ex-Junta Nacional de Granos (JNG), resoluciones de SAGPyA/SENASA, y se operacionaliza a través de las Cámaras Arbitrales de Cereales de Rosario y Buenos Aires. Este informe detalla cada tipo de merma, sus fórmulas exactas, las tablas oficiales, y su tratamiento contable, orientado al desarrollo de software de gestión de inventarios para acopiadores.

***

## Orden de aplicación de las mermas

La **Circular CAC 10/86** de la Cámara Arbitral de Cereales de Rosario y el **Artículo 5° de la Resolución JNG N° 22027/81** establecen el orden obligatorio para la aplicación secuencial de mermas:[^1]

1. **Merma de zarandeo (limpieza)** — se aplica primero sobre el peso bruto neto
2. **Merma de secado** — se aplica sobre el resultado del paso 1
3. **Merma de manipuleo** — se aplica sobre el resultado del paso 2
4. **Merma volátil** — siempre se aplica última

Cada merma se calcula sobre el peso resultante de la merma anterior, no sobre el peso original. Para el software, el cálculo es encadenado multiplicativamente:

\[
\text{Peso\_final} = \text{Peso\_bruto} \times (1 - \%Z) \times (1 - \%S) \times (1 - \%M) \times (1 - \%V)
\]

donde %Z = merma zarandeo, %S = merma secado, %M = merma manipuleo, %V = merma volátil.[^1]

***

## Merma de secado (merma por humedad)

### Fórmula universal

La fórmula aplicada para todos los granos es:[^2][^1]

\[
\%\text{Merma} = \frac{H_i - H_f}{100 - H_f} \times 100
\]

donde:
- \( H_i \) = humedad inicial (real del lote, medida al recibo)
- \( H_f \) = humedad final para el cálculo (no la base comercial, ver tabla abajo)

La fórmula del usuario es conceptualmente correcta:

`peso_seco = peso_humedo × (100 − humedad_real) / (100 − humedad_base)`

Sin embargo, la **humedad final (\( H_f \)) usada en las tablas oficiales no es exactamente la base comercial**, sino un valor **inferior** a la base. La ex-JNG estableció una diferencia que varía por grano para compensar pérdidas adicionales por manipuleo y conservación:[^2]

| Grano | Base comercial (%) | Diferencia (puntos) | \( H_f \) para cálculo de merma (%) |
|---|---|---|---|
| Maíz | 14,5 | 1,0 | 13,5 |
| Sorgo granífero | 15,0 | 1,5 | 13,5 |
| Trigo pan | 14,0 | 0,5 | 13,5 |
| Cebada forrajera | 14,0 | 0,5 | 13,5 |
| Girasol | 11,0 | 0,5 | 10,5 |
| Soja | 13,5 (tolerancia recibo) | 0,5 | 13,0 (base) / 12,5 |
| Cebada cervecera | 12,0 (base) / 12,5 (tol.) | — | Fórmula directa |

Fuente: Documento JNG reproducido en FAO.[^2]

**Nota clave para software**: Soja tiene base 13,5% pero tolerancia de recibo 13,5%. Las tablas de merma comienzan a descontar desde 13,6%. La cebada cervecera **no utiliza tablas tabuladas** sino que aplica directamente la fórmula:[^3][^4][^5]

\[
\text{Merma (\%)} = \frac{(H_i - H_f)}{100 - H_f} \times 100
\]

con \( H_f \) = humedad final pactada (generalmente 12% base).[^4]

\]

## Merma de recibo

**No existe un porcentaje fijo de descuento por recibo**. La "merma de recibo" es un concepto que engloba todos los descuentos que se aplican cuando la mercadería excede las tolerancias establecidas en los estándares de comercialización. Se calcula en función de los parámetros de calidad del lote analizado:[^8][^1]

- **Humedad**: si supera la tolerancia de recibo → merma de secado (tabla) + tarifa de secado
- **Materias extrañas / cuerpos extraños**: si supera la tolerancia → rebaja porcentual
- **Granos dañados, quebrados, etc.**: descuentos sobre precio, no sobre peso
- **Chamico** (girasol, sorgo): descuento por peso y/o precio

Las tolerancias de recibo son el umbral a partir del cual se aplican descuentos. Por debajo de la tolerancia, se recibe sin merma. Las bases y tolerancias clave son:

| Grano | Humedad base (%) | Tolerancia recibo humedad (%) | Materias extrañas tolerancia (%) |
|---|---|---|---|
| Soja | 13,5 | 13,5 | 1,0 (verde, brotado, etc.) |
| Maíz | 14,5 | 14,5 | Según grado (1-3%) |
| Trigo pan | 14,0 | 14,0 | Según grado |
| Girasol | 11,0 | 14,0 | 3,0[^8] |
| Sorgo | 15,0 | 15,0 | Según grado (2-4%)[^14] |
| Cebada cervecera | 12,0 | 12,5 | 0,5[^4] |
| Cebada forrajera | 14,0 | 14,0 | Según grado[^12] |

Para el software: la merma de recibo se construye dinámicamente a partir de cada rubro de calidad del análisis, no como un porcentaje flat.

***

## Merma de zarandeo (limpieza)

La merma por zarandeo se aplica cuando las materias extrañas/impurezas del lote exceden la tolerancia. El cálculo es análogo al de secado, usando impurezas en lugar de humedad:

\[
\%\text{Merma limpieza} = \frac{I_i - I_f}{100 - I_f} \times 100
\]

donde \( I_i \) = porcentaje de impurezas del lote, \( I_f \) = base o tolerancia de materias extrañas.[^15]

En la práctica comercial argentina, muchas normas aplican **descuentos lineales** sobre el precio (no sobre el peso) para materias extrañas. Por ejemplo, en girasol: hasta 3% de materias extrañas se descuenta 1% por cada punto de excedente sobre precio; por encima de 3% se descuenta 1,5% por cada punto.[^8]

Para chamico en sorgo/maíz, la norma establece un descuento fijo de peso: **1,3% de merma de peso más gastos de zarandeo**. Para chamico en girasol, el descuento es de **0,1% sobre el precio por cada semilla en 100 gramos**.[^16][^8]

El costo del servicio de zarandeo se cobra como tarifa aparte (ej. ~USD 4,00/tn, referencia Cámara Arbitral Buenos Aires).[^17]

***

## Merma por manipuleo

Es un porcentaje fijo adicional que se suma a la merma de secado para compensar las pérdidas por transporte interno, movimiento de granos en la planta (carga, descarga, transilaje). Se aplica sobre el peso resultante después de zarandeo y secado.[^1]

| Grano | Merma manipuleo (%) |
|---|---|
| Soja | 0,25[^3] |
| Maíz | 0,25[^6] |
| Trigo pan | 0,10[^7] |
| Girasol | 0,20[^8] |
| Sorgo granífero | 0,25[^9] |
| Cebada forrajera | 0,20[^12] |
| Cebada cervecera | 0,20 (implícito en fórmula) |

***

## Merma volátil

La merma volátil es un descuento regulado que compensa las pérdidas por respiración, acondicionamiento, aireación y procesos biológicos durante el almacenamiento. Está establecida por la **Resolución ex-JNG N° 22027/81, Artículo 5°**:[^1]

| Grupo de granos | Merma volátil máxima (%) |
|---|---|
| Trigo, avena, cebada, centeno, maíz | **0,3** |
| Sorgo, soja, girasol, lino, colza | **0,5** |

La merma volátil es el **porcentaje máximo deducible** y se aplica siempre como última. En la práctica:[^1]

- Se cobra como servicio en la Liquidación Primaria de Granos (LPG)[^18]
- Algunos acopiadores cobran el máximo completo; otros pactan un valor menor
- El simulador de la Bolsa de Cereales de Córdoba excluye la merma volátil de su cálculo automático, indicando que debe agregarse por separado[^19]

Para el software, la merma volátil es un parámetro configurable entre 0 y el máximo legal según tipo de grano.

## Merma de almacenaje

### No existe una tabla estándar regulada de pérdida mensual de peso

A diferencia de las mermas de secado y zarandeo (que son descuentos de peso en la liquidación), la **merma de almacenaje** en el sistema argentino se trata como un **servicio cobrado por tarifa**, no como un descuento de peso regulado. La tarifa referencial históricamente utilizada es:[^17]

- **1,0% mensual sobre el valor del grano** (tarifa base)
- Incremento del **40%** para girasol (= 1,4% mensual del valor)
- Incremento del **10%** para soja (= 1,1% mensual del valor)

Estas tarifas son indicativas de la Cámara Arbitral de Buenos Aires. En terminales portuarias como Quequén, la tarifa se expresa como **USD 0,03/tn/día** (equivalente a ~USD 0,90/tn/mes).[^20][^17]

### Pérdida física real de materia seca

La pérdida real de materia seca por respiración y procesos biológicos no está formalmente tabulada como porcentaje mensual en la normativa comercial argentina, pero estudios del INTA establecen los siguientes parámetros de referencia:[^21][^22]

- Una **pérdida de materia seca (PMS) del 0,5%** está asociada a alteración de calidad que determina la pérdida de un grado comercial[^21]
- Granos secos (11-13% humedad) tienen un proceso respiratorio **lento**[^23]
- Según Marsans (citado en publicaciones de la Asociación de Acopiadores de Córdoba), una masa de granos almacenada por más de seis meses pierde **3% de materia seca si su temperatura sube 10°C por encima de la temperatura inicial**[^24]
- En condiciones adecuadas (grano seco, frío, limpio), la pérdida es **mínima y prácticamente despreciable** a lo largo de una campaña[^25]

Para el software, la recomendación es:
- No modelar una tasa fija de pérdida de peso por almacenamiento
- Modelar el costo de almacenaje como tarifa (% sobre valor o $/tn/día)
- Si se requiere una estimación de pérdida física, usar 0,05-0,1% mensual como referencia aproximada para grano en buenas condiciones, incrementándose significativamente con humedad y temperatura elevadas

### Diferencia silo metálico vs. silo bolsa

La tasa de pérdida no está regulada diferencialmente por tipo de almacenamiento en la normativa comercial. Sin embargo, los estudios del INTA indican diferencias prácticas significativas:[^25]

| Condición | Silo metálico con aireación | Silo bolsa |
|---|---|---|
| Grano seco (≤ base) | Pérdida mínima, almacenamiento prolongado seguro | Bajo riesgo hasta 6 meses; riesgo medio a 12 meses |
| Grano húmedo (base +2-3 puntos) | Requiere secado o aireación reforzada | Riesgo medio a 2 meses; alto a 6 meses |
| Grano muy húmedo (> base +3 puntos) | Secado urgente | Riesgo alto a 1 mes |

En silo bolsa, la temperatura exterior influye: en invierno los granos se conservan mejor que en verano. No existe un diferencial tarifario oficial por tipo de almacenamiento en las normas de la Cámara Arbitral.[^25]

## Tratamiento contable de la merma

### Quién asume el costo

La merma es un **costo para el productor**. Todas las mermas (secado, zarandeo, manipuleo, volátil) se deducen del peso del lote entregado en la **Liquidación Primaria de Granos (LPG)**. El acopiador:[^26][^18]

1. Recibe el grano y emite la Certificación Electrónica de Granos con peso bruto y calidad
2. Aplica los descuentos de merma según tablas oficiales para determinar el **peso neto**
3. Cobra las **tarifas de servicio** (secado, zarandeo, almacenaje, fumigación, merma volátil)
4. Liquida al productor sobre el peso neto

Los **ingresos del acopiador** provienen de los servicios: secada, zaranda, fumigación, merma volátil y gastos generales. La merma volátil, en particular, genera un ingreso directo al acopiador ya que retiene un porcentaje del grano que "desaparece" contablemente.[^18]

### Registración contable

El acopiador registra los kilos netos (ya con mermas descontadas) en los libros de existencias, independientemente de que el grano físico aún no haya sido secado. La diferencia entre kilos brutos recibidos y kilos netos registrados se contabiliza como ingreso por servicios.[^24][^18]

Cuando el acopiador actúa en **consignación**, las diferencias resultantes al cierre entre entradas y salidas se registran como "beneficio o pérdida de conjunto" en cuentas de resultado.[^18]

## Reconciliación física (aforo / cubicaje)

### Procedimiento

El **cubicaje** (aforo) es la determinación aproximada de existencias físicas mediante medición de volumen en los depósitos y conversión a peso usando el peso hectolítrico. La Escuela de Recibidores de Granos de Buenos Aires documenta que este procedimiento tiene un **error de método de aproximadamente 10%** dependiendo del tipo de depósito, la experiencia del operario, y las condiciones del grano.[^24]

Los factores que causan discrepancias entre stock físico y contable incluyen:[^24]
- Diferencia entre mermas de tabla y mermas reales de secado
- Sobresecado (grano que pierde más agua de la registrada)
- Compactación por vibraciones durante almacenamiento
- Temperatura que causa pérdida de materia seca por respiración
- Imprecisión de los medidores de humedad portátiles
- Grano húmedo en silo pero ya neteado en libros

### Tolerancias para diferencias de inventario

No existe en la normativa granaria argentina un porcentaje fijo de tolerancia de aforo equivalente al 0,5% de la normativa de alcoholes. La práctica de la industria acepta:[^27]

- Diferencias de cubicaje de hasta **2-5%** se consideran normales dada la imprecisión del método
- Las inspecciones de **AFIP/ARCA** verifican el Registro Sistémico de Movimientos y Existencias de Granos contra existencias físicas[^18]
- Si las pérdidas reales exceden significativamente lo esperable, el acopiador asume la pérdida como costo propio o la imputa como "pérdida de conjunto"[^18]
- Si se detecta un excedente o faltante significativo, puede constituir una infracción sujeta a inspección

Las mermas que se producen por la propia naturaleza de los granos "deben recuperarse a través de la tarifa de almacenaje".[^24]

## Implementación en software: resumen de fórmulas

### Pseudocódigo de cálculo de peso neto

```
// Datos de entrada del lote
peso_bruto       // kg netos de carta de porte
humedad_real     // % medido
impurezas_real   // % medido
tipo_grano       // enum: SOJA, MAIZ, TRIGO, GIRASOL, SORGO, CEBADA_F, CEBADA_C

// Parámetros por grano (configurar en base de datos)
humedad_base     // % base comercial
humedad_final    // % Hf para cálculo merma secado
tol_humedad      // % tolerancia de recibo humedad
tol_impurezas    // % tolerancia materias extrañas
manipuleo        // % merma por manipuleo
volatil_max      // % merma volátil máxima

// 1. Merma de zarandeo (solo si impurezas > tolerancia)
IF impurezas_real > tol_impurezas THEN
    merma_zarandeo = (impurezas_real - tol_impurezas) / (100 - tol_impurezas) * 100
    // O descuento lineal sobre precio según norma específica
ELSE
    merma_zarandeo = 0
ENDIF
peso_post_zarandeo = peso_bruto * (1 - merma_zarandeo / 100)

// 2. Merma de secado (solo si humedad > tolerancia)
IF humedad_real > tol_humedad THEN
    merma_secado = (humedad_real - humedad_final) / (100 - humedad_final) * 100
    // O buscar en tabla oficial precalculada
ELSE
    merma_secado = 0
ENDIF
peso_post_secado = peso_post_zarandeo * (1 - merma_secado / 100)

// 3. Merma de manipuleo (solo si hubo secado)
IF merma_secado > 0 THEN
    peso_post_manipuleo = peso_post_secado * (1 - manipuleo / 100)
ELSE
    peso_post_manipuleo = peso_post_secado
ENDIF

// 4. Merma volátil (configurable, máximo según JNG 22027/81)
volatil_aplicada = MIN(volatil_pactada, volatil_max)
peso_neto = peso_post_manipuleo * (1 - volatil_aplicada / 100)
```
