# Reference data catalog for Argentine grain trade (quality parameters and ARCA species codes)

## Scope and conventions

This catalog compiles the main commercial grain types used in the Argentine grain trade, linking them to the AFIP/ARCA "especie" codes used in CTG and F.1116 forms and summarizing the standard quality bases from national norms (SAGyP/SENASA Resolution 1075/94 and later amendments) and the Cámara Arbitral de Cereales (Rosario/Buenos Aires).[^1][^2][^3]

Because official norms define full grading systems, this report focuses on the parameters most relevant for ERP master data:

- Base moisture ("humedad base" for pricing / merma tables when explicitly defined).
- Maximum receivable moisture ("tolerancia de recibo" or maximum humidity before the lot is out of standard).
- Base and maximum tolerances for foreign material/dockage ("materias extrañas" / "cuerpos extraños").
- Base test weight ("peso hectolítrico" or specific equivalent where given).
- Tolerances for damaged grain and other key quality rubros that drive discounts.
- Indication of how merma de recibo is handled (fixed percentage vs. official shrink tables).
- Typical Argentine harvest window used as an approximate campaign period.

Where norms only define a **maximum humidity** and do not give a separate base, the "base moisture" column is set equal to that maximum and explicitly noted as "= max (no separate base in norm)" so the ERP can still store a single reference value without introducing data not supported by regulation.[^2][^3]

AFIP/ARCA grain species codes are taken from the official "especies" table used by AFIP web services for CTG and grain settlement forms.[^4]

Harvest windows are synthesized from Argentine agronomic calendars and sector articles; they should be treated as indicative (for campaign grouping) rather than hard cut‑offs.[^5][^6]

## Soybeans (Soja) – code 23

### Regulatory and chamber references

Key references are SAGPyA Resolution 151/2008 (Norma XVII – Soja) and the summary charts published by the Cámara Arbitral de Cereales (Rosario), which reproduce the official bases and tolerances.[^7][^2]

### Core quality parameters

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture (Humedad)                      | 13.5% (base for pricing and shrink)           | 13.5% (above this, apply official merma tables)    | Norm XVII sets a single maximum moisture of 13.5%; excess moisture is discounted via SENASA drying‑loss tables plus drying charges. [^7] |
| Foreign material (Materias extrañas)    | 1.0% total, max 0.5% soil                    | 3.0% total, max 0.5% soil                         | 1–3%: discount equal to % foreign; above 3%: 1.5% price discount per additional point. [^7][^8] |
| Damaged kernels (granos dañados: brotados, fermentados, ardidos, dañados por calor, podridos) | 1.0%                                          | 1.0% (any excess discounted)                       | Over 1.0%: 1.0% price discount per extra point. [^7] |
| Broken/split kernels (granos quebrados y partidos) | 5.0%                                       | 10.0%                                              | Over 5%: 0.2% discount per extra point; UNLP summary details discount ladder up to 30%. [^8] |
| Green beans (granos verdes)             | 5.0%                                          | 5.0% (any excess discounted)                       | Excess over 5.0% discounted at 1.0% per point. [^7] |
| Black beans (granos negros)             | 0.5%                                         | 0.5%                                               | Excess over 0.5%: 1.5% discount per point. [^7] |
| Insects / mites                         | Free                                           | Free                                                | Presence of live insects is cause for rejection (fuera de estándar). [^7] |

### Merma de recibo

- **Moisture shrink:** Calculated from official SENASA/IASCAV shrink tables for soy when moisture exceeds 13.5%, plus a drying tariff; there is no single fixed merma %.[^7]
- **Cleaning shrink:** Specific shrink (e.g., for chamico) is not defined for soy as a separate percentage in the Norma XVII; foreign material is handled via price discounts, not a standard fixed weight deduction.[^7]

### Typical harvest window in Argentina

- Main harvest: **March–June**, with a concentration in **April–May** in core Pampas (Buenos Aires, Córdoba, Santa Fe).[^6][^5]

## Corn (Maíz) – codes 19, 26, 27

### Regulatory and chamber references

Quality parameters follow Norma XII – Maíz under Resolution 1075/94 and subsequent chamber charts (Cámara Arbitral de Cereales – Rosario).[^9][^3][^7]

### Core quality parameters (Maíz amarillo – generic code 19)

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture                                | 14.5% (= max; no lower base defined in Norma XII) | 14.5%                                              | Above 14.5%: apply official humidity merma table plus drying charges. [^7] |
| Foreign material (Materias extrañas)    | 1.0% (Grade 1), 1.5% (Grade 2), 2.0% (Grade 3) | Grade 3 limit 2.0%                                | Above grade limits: price discounts per % excess; chamico handled separately with dedicated merma. [^7] |
| Damaged kernels (granos dañados)        | 3.0% (Grade 1), 5.0% (Grade 2), 8.0% (Grade 3) | 8.0%                                               | Includes heat‑damaged, moldy and rotten kernels; excess drives escalating discounts. [^9][^7] |
| Broken kernels (granos quebrados)       | 2.0% (Grade 1), 3.0% (Grade 2), 5.0% (Grade 3) | 5.0%                                               | Defined as kernels passing a 4.76 mm round‑hole sieve (excluding damaged pieces). [^9][^7] |
| Test weight (Peso hectolítrico mínimo)  | 75 kg/hl (Grade 1)                              | 69 kg/hl (Grade 3)                                  | Below grade weights causes price discounts per kg/hl shortfall. [^7] |
| Chamico (Datura ferox)                  | Up to 2 seeds per 100 g                         | Above: 1.3% merma + cleaning charge                | Chamico presence triggers standard cleaning merma. [^9][^7] |
| Types                                   | Duro (flint) and Dentado                        | —                                                   | Norm defines separate physical descriptions for hard vs. dent corn based on endosperm. [^9] |

### Special corn types

- **Maíz flint o plata (code 26):** Same quality norms as generic corn; differentiation is commercial (hard flint type) rather than regulatory, so ERP may use the same quality template as Maíz (19).[^9][^4]
- **Maíz pisingallo (code 27):** AFIP code distinguishes popcorn; physical quality (humidity, foreign material, damaged grain) follows the generic Maíz norm, but popping expansion and kernel size are usually handled in private contracts, not in Norma XII.[^1]
- **Maíz waxy:** No dedicated AFIP code; typically coded as 19 or 26 with waxy character specified contractually (e.g., as a "tipo" or segregated quality).[^4]

### Merma de recibo

- **Moisture:** Official merma table applied when moisture exceeds 14.5%; the table is non‑linear, so ERP should model shrink as a function of initial and target humidity rather than a single percent.[^10][^3]
- **Cleaning:** Chamico cleaning uses a standard 1.3% weight merma plus zarandeo expenses when seeds exceed tolerance.[^7]

### Typical harvest window in Argentina

- Early / full‑season grain corn: **February–May**.
- Late / second‑crop corn: **March–July**, with overlap depending on region.[^11][^6]

## Bread wheat (Trigo pan) – code 15

### Regulatory and chamber references

Bread wheat is covered by Norma XX – Trigo pan (SAGPyA Resolution 1262/2004 and related) and the Cámara Arbitral trigo charts.[^3][^7]

### Core quality parameters (Trigo pan – condition "Cámara")

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture                                | 14.0% (= max; no lower base defined in Norma XX) | 14.0%                                              | Above 14%: humidity merma table plus drying charges; wheat with higher moisture is out of standard unless otherwise contracted. [^7] |
| Foreign material (Materias extrañas)    | 0.20% (Grade 1), 0.80% (Grade 2), 1.50% (Grade 3) | 1.50%                                           | Includes weed seeds and inert matter; above grade limits discounted. [^7] |
| Total damaged kernels (granos dañados totales) | 1.0% (Grade 1), 2.0% (Grade 2), 3.0% (Grade 3) | 3.0%                                               | Includes heat‑damaged, sprouted, moldy, etc. [^7] |
| Broken / chaffy kernels (granos quebrados y chuzos) | 0.5% (Grade 1), 1.2% (Grade 2), 2.0% (Grade 3) | 2.0%                                           | Defined via specified slotted sieve; broken fraction above tolerances drives discounts. [^7] |
| Test weight (Peso hectolítrico mínimo)  | 79 kg/hl (Grade 1)                              | 73 kg/hl (Grade 3)                                  | Below grade PH triggers specific price discounts per kg/hl. [^7] |
| Panza blanca, carbón, etc.              | Specific limits by grade (e.g., panza blanca up to 15% in Grade 1) | —                                             | Norm defines separate tolerances for chalky kernels, smut, etc., which may be modeled as optional ERP fields. [^7] |
| Insects / mites                         | Free                                           | Free                                                | Live insects cause rejection. [^7] |

### Quality groups and segregations

Norma XX allows for contractual clauses to exclude wheat with insufficient gluten quality (e.g., via Glutomatic or alveograph), establishing functional groups (Grupo I, II, III) often used by chambers and exchanges; these affect premiums rather than basic CTG species coding.[^2][^7]

### Merma de recibo

- **Moisture shrink:** Calculated using SENASA humidity tables above 14%, plus drying tariff.
- **Cleaning shrink:** Where cleaning for chamico or excessive foreign material is performed, merma is applied according to chamber practice (commonly in the 1–2% range for heavy cleaning), typically parameterized by each acopiador; the national wheat norm itself specifies discounts rather than a single cleaning merma.[^10][^7]

### Typical harvest window in Argentina

- Main harvest of winter wheat: **November–January**, depending on latitude (earlier in NOA/NEA, later in southern Buenos Aires).[^6]

## Durum wheat (Trigo candeal) – code 14

Durum wheat (Trigo duro / candeal) follows a dedicated norm structurally similar to bread wheat, with tighter vitreousness and quality requirements.[^1]

For ERP purposes, base humidity and damaged/foreign tolerances can be taken equal to Trigo pan unless contracts specify durum‑specific stricter limits; test weight minima are typically higher (around 80–81 kg/hl) but should be confirmed against the latest chamber tables used by the target market (e.g., Cámara Arbitral de Rosario).[^12]

Campaign period is similar to bread wheat (winter crop, harvest November–January).[^6]

## Sunflower (Girasol) – code 2

### Regulatory and chamber references

The standard is Norma IX – Girasol (Resolution 1075/94 plus later updates and chamber charts).[^13][^3]

### Core quality parameters (in‑shell sunflower)

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture                                | 11.0% (base for pricing and shrink)           | 14.0% (UNLP summary; above that, merma applies)    | In chamber charts, 11% is base; UNLP teaching material cites a 14% receival tolerance with merma above base. [^13][^8] |
| Foreign material (Materias extrañas)    | 0.0% (base)                                   | 3.0% (tolerance)                                   | Up to tolerance: price discount equal to % foreign; above 3%: 1.5% discount per extra point. [^8] |
| Oil content on dry, clean basis (materia grasa S.S.S. y L) | 42% (typical base)                      | —                                                   | Norm IX establishes base oil content with symmetric bonifications and discounts per point around base. [^13] |
| Acid value (acidez de la materia grasa) | Thresholds defined (e.g., 1.5–2.0%)           | Above thresholds: progressive discounts             | Excess acidity indicates quality deterioration. [^13] |
| Insects / mites                         | Free                                           | Free                                                | Live infestation rejected. [^13]

High‑oleic vs. conventional sunflower is differentiated in contracts by minimum oleic acid % in oil, not by separate AFIP species codes.

### Merma de recibo

- **Moisture:** Above 11% moisture, apply official sunflower shrink table plus drying tariff; chambers often allow reception up to ~14% with shrink.[^8][^13]
- **Cleaning:** Foreign material is handled via price discounts in the norm; if acopiador performs mechanical cleaning, an operational cleaning merma (e.g., 1–2%) is typically applied by local policy rather than by regulation.

### Typical harvest window in Argentina

- Sunflower (as a spring‑summer sowing) is usually harvested **December–March**, varying by region (earlier in NEA, later in southern Buenos Aires).[^14][^6]

## Grain sorghum (Sorgo granífero) – code 22

### Regulatory and chamber references

Norma XVIII – Sorgo granífero (updated by SENASA Resolution 554/2011) with chamber summary tables.[^2][^7]

### Core quality parameters (Sorgo granífero)

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture                                | 15.0% (= max; no separate lower base)         | 15.0%                                              | Above 15%: apply humidity merma plus drying tariff, as per official table. [^7] |
| Foreign material + non‑grain sorghum    | 2.0% (Grade 1), 3.0% (Grade 2), 4.0% (Grade 3) | 4.0%                                           | Norm groups foreign matter and non‑grain sorghum in one rubro. [^7] |
| Damaged kernels                         | 2.0% (Grade 1), 3.0% (Grade 2), 4.0% (Grade 3) | 4.0%                                           | Includes moldy, heat‑damaged, etc. [^7] |
| Broken kernels                          | 3.0% (Grade 1), 5.0% (Grade 2), 7.0% (Grade 3) | 7.0%                                           | Defined by passage through 3.17 mm triangular‑hole sieve. [^7] |
| Test weight (Peso hectolítrico mínimo)  | Values by grade (not explicitly shown in excerpt) | Grade 3 minimum set in norm                        | ERP can mirror the grade‑based minima from full Norma XVIII text. [^2] |
| Tannins                                 | For "bajo tanino" / "sin taninos" types, max 5% kernels with condensed tannins | —      | Color and tannin content drive special specifications; handled as optional quality fields. [^7] |
| Insects / mites                         | Free                                           | Free                                                | Live infestation rejected. [^7]

### Merma de recibo

- **Moisture:** SENASA sorghum shrink table above 15%.
- **Cleaning:** Chamico in sorghum has the same 1.3% standard merma plus cleaning costs above tolerance.[^7]

### Typical harvest window in Argentina

- Grain sorghum is usually harvested **March–June**, following late corn in many rotations; no single national calendar exists, but it is a summer crop harvested in autumn.[^6]

Feed/forage sorghums (non‑graníferos) are typically not commercialized as grain through standard grain exchange contracts and therefore are outside CTG grain species scope.

## Malting barley (Cebada cervecera / apta para maltería) – codes 12 and 17

### Regulatory and chamber references

Current malting barley standards are defined in Norma V – Anexo A (Cebada cervecera) as updated by SENASA Resolution 27/2013, with detailed tables reproduced by grain traders and malting companies.[^15][^3]

### Core quality parameters (Cebada cervecera)

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture                                | 12.0% (base)                                  | 12.5%                                              | Below 12%: 1.2% bonus per point; above 12.5%: humidity merma via formula and drying costs. [^15][^3] |
| Foreign material (Materias extrañas)    | 0.5% (max base)                               | 1.0%                                               | >0.5–1.0%: 1% discount per additional point or fraction. [^15] |
| Damaged kernels                         | 0.5% (max base)                               | 1.5%                                               | Bonus for <0.5%, discount ladder up to 1.5%. [^15] |
| Broken / peeled kernels                 | 1.5% (max base)                               | 4.0%                                               | Bonus for values below base; discounts between 1.5 and 4%. [^15] |
| Kernels with smut (carbón)              | 0.0% base                                     | 0.2%                                               | Above 0.2%: 1% discount per extra point. [^15] |
| Under‑sized fraction (<2.2 mm sieve)    | 0.0% base                                     | 4.0%                                               | Bonus for <4%, discounts for >4%. [^15] |
| Calibre ≥ 2.5 mm                        | 85% (min base)                                | 80%                                                | Discounts when calibre drops 85–80%. [^15][^3] |
| Protein (S.S.S.)                        | 9.5% min, 13.0% max                           | Same                                                | Outside this window generally disqualifies for malting use. [^3] |
| Germination capacity                    | 98% (base)                                    | 95%                                                | Below base but above tolerance discounted 0.5% per point. [^15] |
| Insects / mites                         | Free                                           | Free                                                | Live infestation rejected. [^3]

### Merma de recibo

- **Moisture:** formula‑based merma applied above 12.5%, supplied explicitly in Norma V Anexo A; ERP should implement the formula rather than a fixed %.
- **Cleaning:** Foreign material, smut and fine fractions are handled through price discounts; operational cleaning merma is generally a company policy.

### Typical harvest window in Argentina

- Malting barley harvest coincides with winter cereals: **November–January**, slightly earlier on average than wheat in many southern Buenos Aires areas.[^16][^6]

## Peanuts (Maní) – codes 3, 5, 6, 7

### Regulatory and chamber references

Norms for peanuts are in Norma XIII and its annexes, consolidated and updated by SAGPyA Resolutions 225/1997 and 12/1999 (Maní) and subsequent annexes for in‑shell, selection industry, oil industry and confectionery types.[^19][^20]

For ERP, it is practical to distinguish:

- Maní en caja (code 3) – in‑shell peanuts received by shelling plants.
- Maní para industria de selección (code 5) – shelled but not yet fully graded.
- Maní para industria aceitera (code 6).
- Maní tipo confitería (code 7) – high visual and size standards.

Because the official peanut norms are lengthy and highly product‑specific, only the most generic parameters are summarized here.

### Core generic parameters (high‑level)

| Parameter                               | Typical base / standard                         | Typical receivable / tolerance                     | Notes |
|-----------------------------------------|-------------------------------------------------|----------------------------------------------------|-------|
| Moisture (in‑shell)                     | Around 9–10% (varies by Annex type)           | Typically ≤ 11–12% for reception                  | Above limits: humidity merma + drying; exact numbers differ between in‑shell vs. shelled and between industrial/confitería annexes. [^20][^19] |
| Foreign material                        | Very low bases (≈1–2%)                        | Tolerances typically up to 3–4%                   | Includes shells, soil and other seeds; norms give detailed ladders per product. [^20] |
| Damaged kernels                         | Strict limits (especially for confitería)       | Low tolerances (often ≤3–4%)                      | Damage, splits, aflatoxin‑related defects are tightly controlled. [^20] |

Given the complexity and specialization of peanut norms, ERP implementations often maintain **separate quality templates per Annex (XIII, XIIIa, XIIIb, XIIIc, XIIId)** rather than a single "Maní" template.[^21][^20]

### Typical harvest window in Argentina

- Peanuts (Maní) are mainly produced in Córdoba and neighboring provinces; harvest generally runs **April–June**.[^6]

[^28][^29] |
| Test weight (Peso hectolítrico mínimo)  | 49 kg/hl (Grade 1), 46 kg/hl (Grade 2), 43 kg/hl (Grade 3) | 43 kg/hl (Grade 3)                        | [^29] |
| Damaged kernels                         | 1.0% (Grade 1), 2.0% (Grade 2), 3.0% (Grade 3) | 3.0%                                           | [^29] |
| Total damaged + pelados/rotos + foreign | 3.0% (Grade 1), 4.0% (Grade 2), 5.5% (Grade 3) | 5.5%                                           | [^29] |
| Insects / mites                         | Free                                           | Free                                                | [^28]

### Merma de recibo

- Moisture shrink is applied only when moisture exceeds the 14% limit, using official oats shrink tables; cleaning effects are handled via discounts and any operational merma defined by the elevator.[^29]

### Typical harvest window in Argentina

- As a winter cereal and forage grain, oats are harvested in **November–January**, often slightly earlier than wheat.[^6]

## Flax (Lino) – code 1

### Regulatory and chamber references

Flax quality is set by Norma XI – Lino, with concise summary tables available from acopiador associations.[^30][^31]

### Core quality parameters

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture                                | — (no base; only tolerance)                    | 10.0%                                              | Above 10%: apply humidity merma by Lino table plus drying tariff. [^30][^31] |
| Oil content (materia grasa S.S.S. y L)  | 40% (base)                                    | —                                                   | ±1% bonus/discount per point around 40% oil. [^31] |
| Acidity of oil                          | 1.5% (max base)                               | >1.5% discounted 2.5% per point                   | [^31] |
| Foreign material (materias extrañas)    | — (no base; only tolerance)                    | 8.0% (incl. 0.5% soil)                            | Up to 8%: 1% discount per point; above: 1.25% per point. [^31] |
| Insects / mites                         | Free                                           | Free                                                | [^31]

### Merma de recibo

- **Moisture:** shrink from Lino humidity table beyond 10%.
- **Cleaning:** Norm XI includes a specific 0.5–2.0% discretionary discount for "revolcado en tierra"; cleaning merma as weight loss is based on local practice rather than a fixed national percentage.[^30]

### Typical harvest window in Argentina

- Flax, as a winter–spring oilseed, is typically harvested **November–January**, like late rapeseed or early wheat.[^6]

## Paddy rice (Arroz cáscara) – code 21 (and elaborated rice code 35)

### Regulatory and chamber references

Paddy rice quality is governed by Norma II – Arroz cáscara.[^32][^29]

### Core quality parameters (Arroz cáscara)

| Parameter                               | Base / Standard value                          | Max receivable / tolerance (norm)                   | Notes |
|-----------------------------------------|-------------------------------------------------|-----------------------------------------------------|-------|
| Moisture                                | — (no base; only tolerance)                    | 14.0%                                              | Above 14% moisture: merma plus drying costs according to SENASA tables. [^29] |
| Foreign material (materias extrañas)    | Free (base)                                    | 3.0%                                               | Base of commercialisation states "materias extrañas: libre"; tolerance sets max 3%. [^29][^33] |
| Head rice yield (rendimiento en granos enteros) | 54–59% depending on type (base)           | 42–45% depending on type                           | Different bases/tolerances for largo ancho, largo fino, mediano, corto. [^29][^33] |
| Total milled yield (enteros + quebrados) | 68–70% (base)                                | 63–65%                                             | [^29] |

| Insects / mites                         | Free                                           | Free                                                | [^29]

### Merma de recibo

- Humidity shrink applied above 14% based on the Arroz cáscara shrink table included in Norma II; ERP should model this as a function, not a fixed %.[^29]

### Typical harvest window in Argentina

- Rice harvest in Corrientes, Entre Ríos and neighboring areas is typically **February–April**.[^6]

Elaborated (white) rice uses the AFIP species code 35; its commercial specifications are usually governed by private contracts or food standards rather than the Arroz cáscara norm.

## Other points for ERP implementation

### 1. Handling base vs. tolerance for humidity

- Some oilseeds (girasol, colza/canola, lino, cártamo) clearly distinguish a **base humidity** (for which no merma is applied) and a **higher tolerance of receipt** (above which the lot is rejected).[^23][^31][^13][^29]
- For many cereals (wheat, corn, barley, oats, rye, sorghum), the norms specify only a **maximum humidity** (e.g., 14% or 15%) for condition cámara; above that, merma tables apply and the grain may be considered fuera de estándar.[^18][^27][^29][^7]
- In the data model, it is advisable to:
  - Store **base humidity** when explicitly defined by the norm (e.g., Girasol 11%, Colza/Canola 8.5%).
  - Otherwise, store **max receivable humidity** and treat it as both "base" and "limit" for purposes of merma calculation.

### 2. Merma de recibo modeling

- Official norms rarely define a **single fixed merma %** for a grain; instead they provide **tables or formulas** for humidity shrink and specific fixed merma (e.g., 1.3%) only for certain defects such as chamico.[^10][^29]
- For an ERP, merma de recibo is best modeled as:
  - A configurable **function per grain** (e.g., look‑up table or formula of initial vs. base humidity).
  - Optional **fixed merma rules** by defect (e.g., chamico > tolerance → 1.3% weight merma).

### 3. Campaign (harvest period) fields

Based on Argentine calendars, the following indicative harvest windows can be used for campaign grouping:

| Grain                         | Typical Argentine harvest window |
|-------------------------------|-----------------------------------|
| Soja                          | March–June (peak April–May) [^5][^6] |
| Maíz (grain)                  | February–July (region‑dependent) [^11][^6] |
| Trigo pan / Trigo candeal     | November–January [^6] |
| Girasol                       | December–March [^14][^6] |
| Sorgo granífero               | March–June (autumn) [^6] |
| Cebada cervecera / forrajera  | November–January [^16][^6] |
| Maní                          | April–June [^6] |
| Colza / Canola                | October–December [^3][^6] |
| Centeno                       | November–January (winter cereal) [^6] |
| Avena                         | November–January [^29][^6] |
| Lino                          | November–January [^31][^6] |
| Arroz cáscara                 | February–April [^32][^6] |

These periods should be parameterized per region (NEA, NOA, Centro, Sur) if the ERP needs more granularity.

### 4. Grain types not detailed above

- Some species in the AFIP table (cártamo, alpiste, mijo, triticale) are less common in mainstream Argentine bulk trade but are fully covered by Resolution 1075/94 and its annexes.[^3]
- If the ERP must support them, their quality templates can be derived analogously from Normas I (Alpiste), IV (Cártamo), XIV (Mijo), XX (Trigo pan) and others as needed.[^3]

### 5. Maintenance of reference data

- Regulatory norms for basic grains are relatively stable, but **specific norms have been updated** (e.g., sorghum 2011, barley 2013), and new quality standards (e.g., Trigo Plata, Maíz Flint, Trigo Blando) were added in later resolutions.[^3][^1]
- It is recommended that the ERP’s reference data maintenance process include:
  - A linkage to the **norm version and date** for each grain template.
  - The ability to configure **alternative bases and tolerances** per client or per exchange when commercial contracts deviate from condition cámara (e.g., export contracts by calidad convenida under Norma XXV).[^1]
