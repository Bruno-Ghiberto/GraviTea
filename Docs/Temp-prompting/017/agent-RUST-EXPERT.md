## Critical Code Patterns

### 1. lib.rs — Declarative PyO3 Module (Phase 2, T005)

```rust
use pyo3::prelude::*;

mod errors;
pub use errors::*;

/// Returns a greeting from Rust, proving the PyO3 bridge works.
#[pyfunction]
fn hello() -> String {
    "Hello from Rust".to_string()
}

#[pymodule]
mod gravitea_rust {
    use super::*;

    #[pymodule_export]
    use super::hello;
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_hello() {
        assert_eq!(hello(), "Hello from Rust");
    }
}
```

**Key points**:
- `mod errors; pub use errors::*;` at the TOP — makes error types available to the module
- `#[pymodule] mod gravitea_rust` — declarative pattern (PyO3 0.22+)
- `#[pymodule_export] use super::hello;` — exports function to Python
- `#[cfg(test)] mod tests` — Rust-native tests (run via `cargo test`, not Python)

### 2. errors.rs — Error Enum with PyErr Mapping (Phase 2, T006)

```rust
use pyo3::exceptions::{PyIOError, PyRuntimeError, PyValueError};
use pyo3::PyErr;
use thiserror::Error;

#[derive(Error, Debug)]
pub enum GraviteaError {
    #[error("Invalid input: {0}")]
    InvalidInput(String),

    #[error("Crypto error: {0}")]
    CryptoError(String),

    #[error("IO error: {0}")]
    IoError(#[from] std::io::Error),
}

impl From<GraviteaError> for PyErr {
    fn from(err: GraviteaError) -> PyErr {
        match err {
            GraviteaError::InvalidInput(msg) => PyValueError::new_err(msg),
            GraviteaError::CryptoError(msg) => PyRuntimeError::new_err(msg),
            GraviteaError::IoError(err) => PyIOError::new_err(err.to_string()),
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_error_display() {
        let err = GraviteaError::InvalidInput("bad data".to_string());
        assert_eq!(format!("{err}"), "Invalid input: bad data");
    }

    #[test]
    fn test_io_error_from() {
        let io_err = std::io::Error::new(std::io::ErrorKind::NotFound, "file not found");
        let err: GraviteaError = io_err.into();
        assert!(matches!(err, GraviteaError::IoError(_)));
    }
}
```

**Key points**:
- 3 variants: `InvalidInput` → `PyValueError`, `CryptoError` → `PyRuntimeError`, `IoError` → `PyIOError`
- `#[from]` on `IoError` enables automatic `From<std::io::Error>` conversion
- `impl From<GraviteaError> for PyErr` — manual implementation, does NOT depend on thiserror internals
- Tests verify Display formatting and From conversion — these are pure Rust (no Python needed)

### 3. Python Fallback Pattern (Phase 4, T017)

```python
# test_rust_fallback.py
import pytest


def test_fallback_flag_when_extension_unavailable(monkeypatch):
    """Verify _USE_RUST is False when extension import fails."""
    import importlib
    import sys

    # Remove gravitea_rust from sys.modules if present
    sys.modules.pop("gravitea_rust", None)

    # Monkeypatch import to fail
    original_import = __builtins__.__import__

    def mock_import(name, *args, **kwargs):
        if name == "gravitea_rust":
            raise ImportError("Mocked: no Rust extension")
        return original_import(name, *args, **kwargs)

    monkeypatch.setattr("builtins.__import__", mock_import)

    # The fallback module should detect absence and set _USE_RUST = False
    # Test the pattern itself — not a specific app module (none exist yet)
    _USE_RUST = False
    try:
        from gravitea_rust import hello as _rust_hello
        _USE_RUST = True
    except ImportError:
        _USE_RUST = False

    assert _USE_RUST is False


def test_fallback_produces_identical_output():
    """Verify fallback function produces same result type."""
    # Rust version
    try:
        from gravitea_rust import hello as rust_hello
        rust_result = rust_hello()
    except ImportError:
        pytest.skip("Rust extension not installed")

    # Python fallback version
    def python_hello() -> str:
        return "Hello from Python (fallback)"

    python_result = python_hello()

    # Both return strings
    assert isinstance(rust_result, str)
    assert isinstance(python_result, str)


def test_no_errors_in_fallback_operation():
    """Verify fallback pattern doesn't raise exceptions."""
    _USE_RUST = False
    try:
        from gravitea_rust import hello as _rust_hello
        _USE_RUST = True
    except ImportError:
        _USE_RUST = False

    # Regardless of _USE_RUST value, no exception should be raised
    if _USE_RUST:
        result = _rust_hello()
    else:
        result = "Hello from Python (fallback)"

    assert isinstance(result, str)
```

**Adapt as needed** — these are reference patterns, not copy-paste targets. The key requirement is testing the `try/except ImportError` convention with `_USE_RUST` flag toggling.
