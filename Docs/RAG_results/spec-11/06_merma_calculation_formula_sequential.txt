Context: Merma en Operaciones de Acopio de Granos en Argentina: Tablas, Fórmulas y Normativa > Orden de aplicación de las mermas
Text:
La **Circular CAC 10/86** de la Cámara Arbitral de Cereales de Rosario y el **Artículo 5° de la Resolución JNG N° 22027/81** establecen el orden obligatorio para la aplicación secuencial de mermas:[^1]

1. **Merma de zarandeo (limpieza)** — se aplica primero sobre el peso bruto neto
2. **Merma de secado** — se aplica sobre el resultado del paso 1
3. **Merma de manipuleo** — se aplica sobre el resultado del paso 2
4. **Merma volátil** — siempre se aplica última

Cada merma se calcula sobre el peso resultante de la merma anterior, no sobre el peso original. Para el software, el cálculo es encadenado multiplicativamente:

\[
\text{Peso\_final} = \text{Peso\_bruto} \times (1 - \%Z) \times (1 - \%S) \times (1 - \%M) \times (1 - \%V)
\]

donde %Z = merma zarandeo, %S = merma secado, %M = merma manipuleo, %V = merma volátil.[^1]

## Merma de secado (merma por humedad)



La fórmula aplicada para todos los granos es:[^2][^1]

\[
\%\text{Merma} = \frac{H_i - H_f}{100 - H_f} \times 100
\]

donde:
- \( H_i \) = humedad inicial (real del lote, medida al recibo)
- \( H_f \) = humedad final para el cálculo (no la base comercial, ver tabla abajo)

La fórmula del usuario es conceptualmente correcta:

`peso_seco = peso_humedo × (100 − humedad_real) / (100 − humedad_base)`

Sin embargo, la **humedad final (\( H_f \)) usada en las tablas oficiales no es exactamente la base comercial**, sino un valor **inferior** a la base. La ex-JNG estableció una diferencia que varía por grano para compensar pérdidas adicionales por manipuleo y conservación:[^2]

| Grano | Base comercial (%) | Diferencia (puntos) | \( H_f \) para cálculo de merma (%) |
|---|---|---|---|
| Maíz | 14,5 | 1,0 | 13,5 |
| Sorgo granífero | 15,0 | 1,5 | 13,5 |
| Trigo pan | 14,0 | 0,5 | 13,5 |
| Cebada forrajera | 14,0 | 0,5 | 13,5 |
| Girasol | 11,0 | 0,5 | 10,5 |
| Soja | 13,5 (tolerancia recibo) | 0,5 | 13,0 (base) / 12,5 |
| Cebada cervecera | 12,0 (base) / 12,5 (tol.) | — | Fórmula directa |

Fuente: Documento JNG reproducido en FAO.[^2]

**Nota clave para software**: Soja tiene base 13,5% pero tolerancia de recibo 13,5%. Las tablas de merma comienzan a descontar desde 13,6%. La cebada cervecera **no utiliza tablas tabuladas** sino que aplica directamente la fórmula:[^3][^4][^5]

\[
\text{Merma (\%)} = \frac{(H_i - H_f)}{100 - H_f} \times 100
\]

con \( H_f \) = humedad final pactada (generalmente 12% base).[^4]

El cálculo sigue un orden secuencial obligatorio establecido por la Circular CAC 10/86:[^18]

1. **Merma por zarandeo (limpieza):** Si la mercadería tiene materias extrañas por encima de la base, se descuenta la merma correspondiente. Ejemplo: trigo 2% merma y gastos de zarandeo; maíz 1,3%.[^15][^6]
2. **Merma por secado:** Sobre el peso resultante después de zarandeo, se aplica la merma según **tablas de merma por secado** vigentes (publicadas por la Cámara Arbitral para cada grano), que indican el porcentaje de merma según la humedad de ingreso respecto de la humedad base de comercialización.[^19][^20][^21]
3. **Merma por manipuleo:** Sobre el peso resultante después de secado, se aplica un porcentaje fijo: trigo 0,10%; maíz y soja 0,25%; girasol 0,20%.[^6]
4. **Merma volátil:** Se descuenta adicionalmente: 0,3% para cereales (trigo, maíz, avena, cebada, centeno); 0,5% para oleaginosas (soja, girasol).[^22][^6]

**Fórmula simplificada:**

Peso neto bruto → (−zarandeo) → (−secado) → (−manipuleo) → (−merma volátil) = **Peso neto final certificado**

Además se cobra:
- **Tarifa de secada:** Convenida entre las partes o según tarifario de planta.
- **Paritaria:** Cargo por movimiento de grano (energía eléctrica, personal), cobrado como tarifa por tonelada.[^23][^6]

**Datos a capturar en el ERP:**
- Peso neto bruto (kg)
- % de merma y kg descontados por cada concepto (zarandeo, secado, manipuleo, merma volátil)
- Peso neto final certificado (kg)
- Tarifa de secada aplicada
- Tarifa de paritaria
- Costo total de acondicionamiento

## Implementación en software: resumen de fórmulas



```
// Datos de entrada del lote
peso_bruto       // kg netos de carta de porte
humedad_real     // % medido
impurezas_real   // % medido
tipo_grano       // enum: SOJA, MAIZ, TRIGO, GIRASOL, SORGO, CEBADA_F, CEBADA_C

// Parámetros por grano (configurar en base de datos)
humedad_base     // % base comercial
humedad_final    // % Hf para cálculo merma secado
tol_humedad      // % tolerancia de recibo humedad
tol_impurezas    // % tolerancia materias extrañas
manipuleo        // % merma por manipuleo
volatil_max      // % merma volátil máxima

// 1. Merma de zarandeo (solo si impurezas > tolerancia)
IF impurezas_real > tol_impurezas THEN
    merma_zarandeo = (impurezas_real - tol_impurezas) / (100 - tol_impurezas) * 100
    // O descuento lineal sobre precio según norma específica
ELSE
    merma_zarandeo = 0
ENDIF
peso_post_zarandeo = peso_bruto * (1 - merma_zarandeo / 100)

// 2. Merma de secado (solo si humedad > tolerancia)
IF humedad_real > tol_humedad THEN
    merma_secado = (humedad_real - humedad_final) / (100 - humedad_final) * 100
    // O buscar en tabla oficial precalculada
ELSE
    merma_secado = 0
ENDIF
peso_post_secado = peso_post_zarandeo * (1 - merma_secado / 100)

// 3. Merma de manipuleo (solo si hubo secado)
IF merma_secado > 0 THEN
    peso_post_manipuleo = peso_post_secado * (1 - manipuleo / 100)
ELSE
    peso_post_manipuleo = peso_post_secado
ENDIF

// 4. Merma volátil (configurable, máximo según JNG 22027/81)
volatil_aplicada = MIN(volatil_pactada, volatil_max)
peso_neto = peso_post_manipuleo * (1 - volatil_aplicada / 100)
```
