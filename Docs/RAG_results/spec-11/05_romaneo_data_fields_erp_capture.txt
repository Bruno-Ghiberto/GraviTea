Text:
- **Error 1508** — Non-consecutive order number. Solution: call `liquidacionUltimoNroOrdenConsultar` to get the last accepted order number and use the next integer.[^4]
- **Error 1645** — Was "maximum one certificate per liquidation" (removed since v1.5; multiple certificates are now allowed).[^3]
- **Error 1856** — When providing a retention certificate number, `alicuota` must be `0`.[^3]
- **Error 600** — No data found; typically when querying a non-existent COE or order number.[^4]
- **Error 800** — Service temporarily unavailable; implement retry logic.[^4]
