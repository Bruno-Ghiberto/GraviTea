## Merma de secado (merma por humedad)



La fórmula aplicada para todos los granos es:[^2][^1]

\[
\%\text{Merma} = \frac{H_i - H_f}{100 - H_f} \times 100
\]

donde:
- \( H_i \) = humedad inicial (real del lote, medida al recibo)
- \( H_f \) = humedad final para el cálculo (no la base comercial, ver tabla abajo)

La fórmula del usuario es conceptualmente correcta:

`peso_seco = peso_humedo × (100 − humedad_real) / (100 − humedad_base)`

Sin embargo, la **humedad final (\( H_f \)) usada en las tablas oficiales no es exactamente la base comercial**, sino un valor **inferior** a la base. La ex-JNG estableció una diferencia que varía por grano para compensar pérdidas adicionales por manipuleo y conservación:[^2]

| Grano | Base comercial (%) | Diferencia (puntos) | \( H_f \) para cálculo de merma (%) |
|---|---|---|---|
| Maíz | 14,5 | 1,0 | 13,5 |
| Sorgo granífero | 15,0 | 1,5 | 13,5 |
| Trigo pan | 14,0 | 0,5 | 13,5 |
| Cebada forrajera | 14,0 | 0,5 | 13,5 |
| Girasol | 11,0 | 0,5 | 10,5 |
| Soja | 13,5 (tolerancia recibo) | 0,5 | 13,0 (base) / 12,5 |
| Cebada cervecera | 12,0 (base) / 12,5 (tol.) | — | Fórmula directa |

Fuente: Documento JNG reproducido en FAO.[^2]

**Nota clave para software**: Soja tiene base 13,5% pero tolerancia de recibo 13,5%. Las tablas de merma comienzan a descontar desde 13,6%. La cebada cervecera **no utiliza tablas tabuladas** sino que aplica directamente la fórmula:[^3][^4][^5]

\[
\text{Merma (\%)} = \frac{(H_i - H_f)}{100 - H_f} \times 100
\]

con \( H_f \) = humedad final pactada (generalmente 12% base).[^4]

No se aplica tabla pre-tabulada. La norma SENASA Res. 27/2013 prescribe la fórmula directa para humedad superior a 12,5%:[^13][^4]

\[
\text{Merma (\%)} = \frac{H_i - H_f}{100 - H_f} \times 100
\]

El software debe parametrizar \( H_f \) como la humedad base o la pactada contractualmente.

Text:
Charged when grain moisture exceeds the base standard (14% for wheat and corn, 13% for soy, 11% for sunflower). Drying is the highest-cost conditioning service.[^1]

- **Calculation methods** (from ERP documentation):[^3]
  - **Basic drying**: A tariff for a first humidity range (e.g., 14.6%–17% for corn), plus a per-point-excess surcharge for higher moisture
  - **Decimal point drying**: Charges fractional humidity (e.g., 17.2% charges only two tenths, not rounded up)
  - **Range-based drying**: Different tariffs per defined humidity brackets
- **Merma por secado (drying shrinkage)**: Calculated with the formula: \(%M = \frac{H_i - H_f}{100 - H_f} \times 100\) where \(H_i\) is initial humidity and \(H_f\) is the commercial base humidity. Official tables published by the Cámara Arbitral de Cereales de Rosario provide exact percentages for each tenth of a percent.[^9][^10][^11]
